一、单一用途说明（Single purpose）
--------------------------------------------------------------------------------

HxxTranslate 的唯一用途是翻译用户当前打开的网页文本。用户选择目标语言后，扩展抽取页面可见文字，调用 HxxBot 翻译接口，并将译文写回页面；同时支持选区/首段翻译、原文对照显示、恢复原文、可选自动翻译，以及通过 HxxBot 账号登录并查询翻译额度。扩展不做广告、不做浏览历史分析，也不提供与网页翻译无关的功能。


--------------------------------------------------------------------------------
二、远程代码（Remote code）
--------------------------------------------------------------------------------

【推荐选项】不使用远程代码 → 选择「否」

本扩展所有可执行脚本均随安装包分发（popup、options、service worker、content script），不会从远程服务器下载或执行 JavaScript，也不会使用 eval 或动态注入远程脚本。

【仅当表单强制要求填写理由时粘贴】
本扩展不执行远程代码。运行所需脚本全部打包在扩展内。与 hxxbot.com 的网络请求仅用于 OAuth 登录、账户/额度查询以及提交待翻译文本并接收 JSON 译文数据；返回内容按文本数据处理，不会作为可执行代码加载或运行。


--------------------------------------------------------------------------------
三、主机权限（Host permissions）
--------------------------------------------------------------------------------

主机权限仅用于访问 HxxBot 官方服务（hxxbot.com / www.hxxbot.com），以便：完成桌面端 OAuth 登录、查询账户与翻译额度、将用户发起翻译时抽取的文本片段发送到翻译 API 并接收译文。扩展不会用该权限抓取任意第三方网站内容作为主机权限目标；页面文本的读写通过内容脚本在用户当前标签页内完成。本地开发环境中的 localhost 权限仅用于调试，生产环境默认只请求官方 HxxBot 地址。


--------------------------------------------------------------------------------
四、activeTab 权限
--------------------------------------------------------------------------------

用于在用户点击扩展图标或主动发起翻译时，访问当前活动标签页，以便向该页面注入/通信内容脚本、抽取可见文本并写回译文。仅作用于用户正在操作的当前标签页，不会在后台静默扫描其他标签页。


--------------------------------------------------------------------------------
五、identity 权限
--------------------------------------------------------------------------------

用于通过 chrome.identity 发起 HxxBot 桌面端 OAuth 登录（launchWebAuthFlow），安全获取并保存登录凭证，以便调用翻译与账户接口、查询订阅与剩余额度。不用于访问用户的 Google 账号资料，也不将登录能力用于翻译以外的目的。


--------------------------------------------------------------------------------
六、scripting 权限
--------------------------------------------------------------------------------

用于在用户翻译网页时，向当前标签页注入或确保内容脚本可用，以便抽取页面文本、显示翻译进度/悬浮控制条，并将译文写回 DOM。不会向未请求翻译的页面注入无关脚本，也不会执行来自远程服务器的脚本文件。


--------------------------------------------------------------------------------
七、storage 权限
--------------------------------------------------------------------------------

用于在本地（chrome.storage.local）保存用户设置与登录状态，例如目标语言、界面语言、显示方式、自动翻译开关、悬浮条位置，以及 HxxBot 登录 token。设置仅保存在用户本机浏览器中，用于下次启动恢复偏好，不用于广告或跨站追踪。


--------------------------------------------------------------------------------
八、tabs 权限
--------------------------------------------------------------------------------

用于查询当前活动标签页并向其发送消息（翻译、恢复原文、同步显示模式与悬浮面板），以及在用户选择订阅时打开 HxxBot 会员中心页面。不用于读取完整浏览历史，也不会监控用户未主动操作的标签页内容。


--------------------------------------------------------------------------------
九、数据使用情况确认（Data usage）
--------------------------------------------------------------------------------

请在「隐私权规范」中勾选确认：本产品的数据使用符合 Chrome 网上应用店开发者计划政策。

建议同时勾选/声明的要点（按后台实际选项填写）：
• 收集的用户数据：账号信息（登录后的用户标识/邮箱）、网页内容中的待翻译文本片段（仅在用户发起翻译时）、以及本地保存的扩展设置。
• 用途：提供网页翻译功能、账号认证、额度与订阅管理、改进服务可用性。
• 不出售用户数据；不将数据用于与扩展单一用途无关的目的。
• 翻译相关文本仅发送至 HxxBot（hxxbot.com），不发送至其他第三方服务器。
• 用户可通过退出登录清除本地登录态；可在浏览器中卸载扩展以删除本地存储。


--------------------------------------------------------------------------------
十、英文版（可选，主语言为 English 时粘贴）
--------------------------------------------------------------------------------

Single purpose:
HxxTranslate’s sole purpose is to translate the text of the webpage the user is viewing. After the user chooses a target language, the extension extracts visible text, calls the HxxBot translation API, and writes translations back into the page. It also supports selection/first-paragraph translation, bilingual display, restore original, optional auto-translate, and HxxBot sign-in for quota. It does not show ads, analyze browsing history, or provide unrelated features.

Remote code:
Recommended answer: No. All executable scripts are bundled with the extension. Network calls to hxxbot.com return JSON translation/account data only and are not executed as code.

Host permissions:
Used only to reach HxxBot (hxxbot.com) for OAuth sign-in, account/quota queries, and sending text segments for translation. Page content is handled via the content script in the user’s current tab, not by scraping arbitrary hosts through host permissions.

activeTab:
Used when the user opens the extension or starts translation, so the extension can work with the active tab to extract text and apply translations.

identity:
Used for HxxBot desktop OAuth via chrome.identity.launchWebAuthFlow so the user can sign in and use translation quota. Not used to access Google account profile data for other purposes.

scripting:
Used to inject or ensure the content script is available on the current tab so text can be extracted and translations written back. Does not load or run remote scripts.

storage:
Used to store settings and sign-in state locally (target language, UI language, display mode, auto-translate, floating panel position, auth token).

tabs:
Used to find the active tab, message it for translate/restore/sync UI, and open the HxxBot subscription page when requested. Not used to read full browsing history.

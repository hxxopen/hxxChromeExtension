# HxxTranslate 朗读功能（TTS）设计文档

**版本**：v1.0  
**日期**：2026-09-23  
**适用**：Chrome 扩展 Manifest V3  
**实现方式**：纯前端（`chrome.tts` API + 可选 `speechSynthesis`）  
**目标语言**：英文朗读（en-US / en-GB）

---

## 1. 功能目标

为现有翻译扩展增加**英文文本朗读**能力，支持：

- **整页朗读**：自动按段落/句子拆分，一次只播放一小段，支持上一段 / 下一段切换
- **选中内容朗读**：朗读用户当前选中的文本
- 播放过程中高亮当前段落
- 可调节语速、选择语音
- 与现有「翻译当前网页」「翻译选中/首段」操作逻辑保持一致

---

## 2. 界面入口设计

### 2.1 弹窗（Popup）新增区域

在现有「翻译当前网页」「翻译选中/首段」按钮下方新增「朗读」分组：

| 按钮 | 功能 | 说明 |
|------|------|------|
| 🔊 朗读当前网页 | 整页分段朗读 | 自动提取页面正文段落，按段播放 |
| 🔊 朗读选中内容 | 朗读选中文本 | 无选中时按钮禁用或提示 |

按钮风格与现有白色圆角按钮一致，左侧加喇叭图标。

### 2.2 右侧浮动控制条（核心入口）

现有蓝色「译」按钮扩展为可上下拖动的窄条，鼠标靠近自动展开。

**收起状态**（默认）：
- 仅显示「译」按钮（保持原有行为）

**展开状态**（鼠标靠近或点击）：
```
┌──┐
│译│  ← 翻译整页 / 选中
├──┤
│🔊│  ← 朗读整页（分段）
├──┤
│▶ │  ← 朗读选中（有选中时高亮）
├──┤
│⚙ │  ← 快捷打开朗读设置
└──┘
```

**播放中状态**（自动切换）：
```
┌──┐
│⏸ │  ← 暂停 / 继续
├──┤
│◀ │  ← 上一段
├──┤
│▶ │  ← 下一段
├──┤
│⏹ │  ← 停止
├──┤
│3/12│ ← 当前段 / 总段数
└──┘
```

- 支持上下拖动位置（记忆上次位置）
- 鼠标离开后自动收起（播放中除外）

### 2.3 页面内迷你播放器（播放时出现）

点击朗读后，在页面右下角（可拖动）出现轻量播放器：

```
┌──────────────────────────────────────────┐
│ 🔊 正在朗读 · 第 3 / 12 段               │
│                                          │
│ There are three things entrepreneurs     │
│ can sell online: products, services...   │  ← 当前段落预览（可点击跳转）
│                                          │
│ [◀ 上一段]   [⏸ 暂停]   [下一段 ▶]      │
│                                          │
│ 语速  ────●────  1.0x                    │
│                                          │
│                              [关闭 ×]    │
└──────────────────────────────────────────┘
```

- 当前朗读段落在页面上**浅蓝色高亮**
- 播放器可拖动、可最小化成小圆点
- 整页模式下自动一段接一段播放

### 2.4 设置页面新增「朗读设置」

在现有「页面控制条」下方新增区块：

```
朗读设置
├─ 默认语音          [系统英文语音 ▼]（优先 en-US）
├─ 语速              0.8x ────●──── 1.5x（默认 1.0x）
├─ ☑ 整页朗读时按段落拆分（推荐）
├─ ☑ 朗读时高亮当前段落
├─ ☑ 播放结束后自动停止
└─ ☑ 记住上次语速与语音
```

## 3. 交互流程

### 3.1 整页朗读流程
1. 用户点击「朗读当前网页」或浮动条 🔊
2. Content Script 提取页面正文段落（优先已翻译区域，或使用 Readability 思路过滤导航/广告）
3. 按段落（或句子）拆分为数组 `segments[]`
4. 调用 `chrome.tts.speak(segments[0], { lang: 'en-US', rate, onEvent })`
5. 显示迷你播放器 + 高亮第 1 段
6. 当前段 `end` 事件后自动播放下一段（或用户手动切换）
7. 用户可随时暂停、跳段、停止

### 3.2 选中内容朗读流程
1. 用户选中文本 → 点击「朗读选中内容」或浮动条 ▶
2. 直接朗读选中文本（过长时仍可按句拆分）
3. 无选中时提示「请先选中英文内容」

### 3.3 高亮逻辑
- 给当前段落添加临时 class（如 `.hxx-tts-highlight`）
- 背景色建议：`rgba(59, 130, 246, 0.15)`（蓝色半透明）
- 播放结束后自动移除高亮

## 4. 技术实现要点（纯前端）

### 4.1 权限
```json
{
  "permissions": [
    "tts",
    "activeTab",
    "storage",
    "contextMenus"
  ]
}
```

### 4.2 核心 API
- 优先使用 `chrome.tts`（扩展专用，更稳定）
- 备选 `window.speechSynthesis`（无需权限，但长文本易截断）

### 4.3 分段策略
```js
// 简单可靠的分段方式
function splitIntoSegments(text) {
  // 1. 先按段落
  let paras = text.split(/\n+/).filter(p => p.trim().length > 20);
  // 2. 过长段落再按句子拆
  return paras.flatMap(p => {
    if (p.length < 280) return [p];
    return p.match(/[^.!?]+[.!?]+/g) || [p];
  });
}
```

### 4.4 状态管理
使用 `chrome.storage.local` 保存：
- 语速、选中的 voiceName
- 浮动条位置
- 是否开启高亮 / 自动拆段

## 5. UI 风格规范（保持现有一致性）

| 元素 | 规范 |
|------|------|
| 主色 | `#3B82F6`（蓝色按钮） |
| 圆角 | `12px` / `9999px`（胶囊） |
| 字体 | 系统默认中文 + 英文无衬线 |
| 阴影 | 轻量 `0 4px 12px rgba(0,0,0,0.08)` |
| 高亮 | `rgba(59, 130, 246, 0.15)` |
| 浮动条宽度 | 收起 40px，展开约 48px |
| 播放器宽度 | 约 320–360px |

## 6. 开发优先级建议

1. **P0**：右侧浮动条扩展 + 整页/选中朗读基础功能
2. **P1**：迷你播放器 + 段落高亮 + 上一段/下一段
3. **P2**：设置页语音/语速选项 + 记忆
4. **P3**：右键菜单「朗读选中」、快捷键支持
